Sobre o projeto

Nasceu da necessidade
de uma startup real

A SafeCash é uma startup de antecipação de recebíveis que enfrentava um problema crítico: sistemas legados com duplicidade de lançamentos e ausência total de trilha de auditoria.

O FinTech Flow é a resposta: uma plataforma fullstack construída com Node.js + React, projetada para que pequenas empresas gerenciem seu fluxo de caixa com a mesma precisão de um banco.

Fazer parte da solução
✓

Sem duplicidade

Validações rigorosas impedem lançamentos duplicados em qualquer camada do sistema.

◷

Trilha de auditoria

Todo registro mantém histórico de criação e alteração com identificação do responsável.

⊘

Soft delete

Nenhum dado é apagado fisicamente. A rastreabilidade total é garantida por arquitetura.

↻

Saldo em tempo real

O dashboard atualiza automaticamente a cada transação registrada.

Segurança

Construído para não falhar

No mercado financeiro, um bug não é apenas um inconveniente: pode significar prejuízos milionários. O FinTech Flow foi arquitetado com múltiplas camadas de proteção.

  • ✓ Validação de schema em todas as rotas da API
  • ✓ Bloqueio de valores absolutos negativos
  • ✓ Exclusão lógica (soft delete) obrigatória
  • ✓ Rastreabilidade de autoria por registro
  • ✓ Controle de versão com Git e histórico de merges
